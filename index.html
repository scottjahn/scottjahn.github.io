A few things I (well mostly Claude ;) ) build in my spare time — a league stats portal, two browser games that also ship as Android apps, and a yearly Advent of Code habit.

Projects

  • HWPL Manager

    Stats portal for the Hiram Walker Pickleball League. Player, team and league tables with drill-down detail pages, plus per-court session results. The public site is fully static — stats are snapshotted from a local SQLite database at build time, so there's no backend to run.

    Open the site · Source

  • Power of 2 Game

    A number-merge puzzle: swipe matching tiles together to build bigger ones. Written as an offline-capable PWA — one page, no framework, playable from the browser or installed to a home screen.

    Play · Source

  • World of War Game

    A 2D top-down autobattler in the spirit of Totally Accurate Battle Simulator. Both sides buy and place an army against a shared budget, then the battle runs itself and declares a winner. One engine, four editions — Earth, Animals, Space and Prehistoric — each with its own roster, maps and rules.

    Play · Source

    My solutions to the yearly Advent of Code puzzles, kept in one repository year by year.
