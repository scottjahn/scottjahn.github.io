A few things I (well mostly Claude ;) ) build in my spare time — stats trackers for pickleball and Dominion, three browser games (two of which also ship as Android apps), a trainer for my own chess mistakes, and my yearly Advent of Code solutions.

Projects

  • HWPL Manager

    Stats portal for the Hiram Walker Pickleball League. Player, team and league tables with drill-down detail pages, plus per-court session results. The public site is fully static — stats are snapshotted from a local SQLite database at build time, so there's no backend to run.

    Open the site · Source

  • Power of 2 Game

    A number-merge puzzle: swipe matching tiles together to build bigger ones. Written as an offline-capable PWA — one page, no framework, playable from the browser or installed to a home screen.

    Play · Source

  • World of War Game

    A 2D top-down autobattler in the spirit of Totally Accurate Battle Simulator. Both sides buy and place an army against a shared budget, then the battle runs itself and declares a winner. One engine, four editions — Earth, Animals, Space and Prehistoric — each with its own roster, maps and rules.

    Play · Source

  • War of Worldships Game

    A 3D naval combat game in the style of World of Warships, built for my 8-year-old. You command a real warship against bot fleets, earning XP toward a tech tree of 157 historical hulls across five navies. The 3D view is a small perspective renderer written from scratch onto a plain 2D canvas — no WebGL, no libraries, nothing to install.

    Play · Source

  • Dominion Scores

    Score tracker for our Dominion games. Because a 40-point win means nothing on its own — the kingdom decides whether that's a runaway or a squeaker — every player's game is scored against the rest of that same table rather than against raw history. Standings, head-to-head records and per-year splits, built the same static way as the pickleball site.

    Open the site · Source

  • Chess Mistake Trainer

    Drill the moves you actually got wrong. Import your chess.com games, let Stockfish find your mistakes, record the move you should have played, and practise those positions as puzzles. Games, database and engine stay on my machine — the published trainer is one exported puzzle file, so anyone with the link can try the set and keep their own score.

    Open the trainer · Source
